# tw-stock-digest

台股／美股盤後資料整理腳本。抓官方與公開資料，算出持股的技術面、籌碼面基礎分，並整理當天的熱門股（強勢族群、爆量、法人大買），輸出成文字報告，給 AI 撰寫每日手機推播。

只用 Python 標準函式庫，不需要安裝任何套件。

## 用法

```bash
python3 stock_digest.py --tw 2308,2454 --us GOOGL,MU --out /tmp/stock
```

會產生：

- `holdings.txt`：每檔持股的均線、KD、MACD、RSI、布林、轉折點、近 8 日 K 線、三大法人、集保大戶／散戶週變化、主動式 ETF 加減碼、新聞
- `hot.txt`：漲幅 ≥ 7% 個股與共同特徵、產業強度、爆量股、外資／投信買超排行
- `data.json`：原始資料

其他參數：

- `--date 2026-10-08`：用指定日期的資料跑（測試用）
- `--skip-hot`：不算熱門股
- `--push messages.json --topic <ntfy topic>`：把整理好的訊息送到 [ntfy](https://ntfy.sh)，太長的訊息會自動拆開

## 評分方式

技術面基礎分（0–10）

| 項目 | 配分 |
|---|---|
| 收盤站上 5／10／20／60 日線 | 3 |
| 均線多頭排列、月線上揚 | 2 |
| MACD（零軸上、柱狀體翻紅、柱狀體增加） | 1.5 |
| KD（K > D、未過熱） | 1 |
| RSI 介於 50–75 | 0.5 |
| 量價關係（價漲量增、量縮回檔） | 1.5 |
| 突破 20 日高點 | 0.5 |

籌碼面基礎分（0–10，台股）

| 項目 | 配分 |
|---|---|
| 成交量配合漲跌 | 2 |
| 三大法人（今日、5 日、20 日、連續買賣超） | 3 |
| 集保大戶（≥400 張）與散戶（≤100 張）持股比例週變化 | 3 |
| 主動式 ETF 新增、加碼、減碼、剔除 | 2 |

缺資料的項目不計分，依有資料的滿分換算成 0–10。美股沒有三大法人與集保，改用成交量、機構與內部人持股變化、空單比例、分析師評等與目標價。

## 資料來源

- 臺灣證券交易所：每日收盤行情、三大法人買賣超、公司基本資料、處置股
- 證券櫃檯買賣中心：上櫃行情、三大法人買賣明細、處置股
- 臺灣集中保管結算所：集保戶股權分散表
- [FinMind](https://finmindtrade.com)：個股歷史股價、法人歷史、新聞、產業分類、美股股價
- [TANGCHIH0221/active-etf](https://github.com/TANGCHIH0221/active-etf)：台股主動式 ETF 每日持股異動
- finviz：美股空單、機構與內部人持股
- Google News RSS

請遵守各資料來源的使用規範，避免短時間大量請求。
