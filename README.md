# tw-stock-digest

台股／美股盤後資料整理腳本。抓官方與公開資料，算出持股與大盤（加權、櫃買、S&P 500、那斯達克、費半）的技術面、籌碼面基礎分，並整理當天的熱門股（強勢族群、爆量、法人大買），輸出成文字報告，給 AI 撰寫每日手機推播。

只用 Python 標準函式庫，不需要安裝任何套件。

## 用法

```bash
python3 stock_digest.py --tw 2308,2454 --us GOOGL,MU --out /tmp/stock
```

會產生：

- `holdings.txt`：每檔持股的均線、KD、MACD、RSI、布林、轉折點、近 8 日 K 線、三大法人、集保大戶／散戶週變化、主動式 ETF 加減碼、新聞
- `hot.txt`：漲幅 ≥ 7% 個股與共同特徵、產業強度、爆量股、外資／投信買超排行
- `market.txt`：大盤的技術面、籌碼面（台股：三大法人、外資台指期未平倉、融資融券、融資維持率；美股：機構出貨日、量價、VIX）
- `data.json`：原始資料

其他參數：

- `--date 2026-10-08`：用指定日期的資料跑（測試用）；`--date prev`＝前一個台股交易日（早上推台股用）
- `--part tw`／`--part us`：只做台股（持股、台股大盤、熱門）或只做美股（持股、美股大盤）
- `--skip-hot`：不算熱門股
- `--push messages.json --topic <ntfy topic>`：把整理好的訊息送到 [ntfy](https://ntfy.sh)，太長的訊息會自動拆開
- `--push messages.json --telegram`：改送到 Telegram 機器人，照閱讀順序送出。機器人 token 讀環境變數 `TELEGRAM_BOT_TOKEN_2`（可用 `--telegram-token-env` 換成別的變數名），chat_id 讀 `TELEGRAM_CHAT_ID`（或用 `--telegram-chat <chat_id>` 指定）

## 評分方式

技術面基礎分（0–10）

| 項目 | 配分 |
|---|---|
| 收盤站上 5／10／20／60 日線 | 3 |
| 均線多頭排列、月線上揚 | 2 |
| MACD（零軸上、柱狀體翻紅、柱狀體增加） | 1.5 |
| KD（K > D、未過熱） | 1 |
| RSI 介於 50–75 | 0.5 |
| 量價關係（價漲量增、量縮回檔） | 1.5 |
| 突破 20 日高點 | 0.5 |

籌碼面基礎分（0–10，台股）

| 項目 | 配分 |
|---|---|
| 成交量配合漲跌 | 2 |
| 三大法人（今日、5 日、20 日、連續買賣超） | 3 |
| 集保大戶（≥400 張）與散戶（≤100 張）持股比例週變化 | 3 |
| 主動式 ETF 新增、加碼、減碼、剔除 | 2 |

缺資料的項目不計分，依有資料的滿分換算成 0–10。美股沒有三大法人與集保，改用成交量、機構與內部人持股變化、空單比例、分析師評等與目標價。

大盤技術面（0–10，台股美股共用）

| 項目 | 配分 |
|---|---|
| 站上 5 日線 0.5、月線 1、季線 1、年線（美股 200 日線）0.5 | 3 |
| 月線、季線上揚，5>20>60、月>季>年 多頭排列 | 2 |
| MACD 柱 > 0、DIF > 0、KD K > D、12 週 RSI > 50（中期多空分界） | 2 |
| 量價關係 | 1.5 |
| 距 52 週高點（<5% 滿分、≥10% 修正 0 分）；台股加漲跌家數比，美股加 50 日線 > 200 日線 | 1.5 |

大盤籌碼面（0–10）

| 台股 | 配分 | 美股 | 配分 |
|---|---|---|---|
| 外資現貨（今日、5 日、10 日、連買） | 3 | 機構出貨日（IBD：25 日內跌 ≥0.2% 且量增的天數） | 4 |
| 投信＋自營商 5 日 | 1 | 近 10 日上漲日量／下跌日量 | 3 |
| 外資台指期淨未平倉（水位與增減） | 2.5 | VIX 恐慌指數（水位、相對 50 日均） | 3 |
| 融資增減與指數背離 | 1.25 | | |
| 大盤融資維持率（165–185% 健康） | 1.25 | | |
| 券資比變化 | 1 | | |

美股沒有公開的每日法人買賣與融資融券資料，所以改用上面三項。S&P 500 和費半指數沒有成交量，分別用 SPY、SOXX ETF 的量代替。

## 資料來源

- 臺灣證券交易所：每日收盤行情、加權指數、三大法人買賣超與金額、融資融券、公司基本資料、處置股
- 證券櫃檯買賣中心：上櫃行情、櫃買指數、三大法人買賣明細與金額、融資融券、處置股
- 臺灣期貨交易所：三大法人台指期未平倉
- CNBC、Yahoo Finance：美股指數、VIX、美股持股日 K
- 臺灣集中保管結算所：集保戶股權分散表
- [FinMind](https://finmindtrade.com)：個股歷史股價、法人歷史、新聞、產業分類、美股股價
- [TANGCHIH0221/active-etf](https://github.com/TANGCHIH0221/active-etf)：台股主動式 ETF 每日持股異動
- finviz：美股空單、機構與內部人持股
- Google News RSS

請遵守各資料來源的使用規範，避免短時間大量請求。
